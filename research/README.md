# AugLeak research code

The research behind [augleak.vercel.app](https://augleak.vercel.app): code, data recipes and paper for **"Copies Across the Split: Pre-Augmented Datasets Silently Corrupt Test Accuracy, and How to Audit Them Without Metadata"**.

Many public image datasets ship every photograph together with rotated, flipped, recoloured and filtered copies, and do not record which files belong together. A random train/test split of such a release puts a copy of almost every test image in the training set. This repository contains:

- `augleak_cli.py`, a command-line auditor that finds hidden copies without metadata and produces a leak-aware evaluation;
- every experiment in the paper (CPU only, no GPU needed);
- the LaTeX source of the paper in three formats: `paper_tmlr/`, `paper_neurips/` and `paper/` (ICLR 2027).

Run everything from this folder (`cd research`). The browser and API versions of the detector live in [`../apps/web/src/lib/engine`](../apps/web/src/lib/engine) and reproduce this code's results (see [`../apps/web/tests/parity.test.ts`](../apps/web/tests/parity.test.ts)).

## Quick start: audit your own dataset

The dataset must have one folder per class (`data/<class>/*.jpg`).

```bash
pip install -r requirements.txt

# 1. find copies inside a release (links, detected groups, byte-identical files, label conflicts)
python augleak_cli.py scan data/ --alpha 1e-3 --out report/

# 2. audit an existing split: which test images have a copy in train?
python augleak_cli.py test data/train data/test --out report/
#    -> report/flagged.csv, report/clean_test.txt, report/report.md

# 3. make a group-aware split from the detected groups
python augleak_cli.py split data/ --test-frac 0.2 --out split/
```

`--alpha` is the per-image false-link rate the detector is calibrated to (lower means fewer, surer links). Detected groups are a lower bound on the true grouping. Report the accuracy on `clean_test.txt` together with its size.

## How it works

Each image is compared with every other image of the same class in two pixel views:

1. **structure view**: a blurred grey thumbnail inside a centred disc, matched over flips, quarter-turns, rotations up to 45° and crops; it survives colour changes and filters such as CLAHE, thresholding or gamma;
2. **hash view**: a 64-bit DCT perceptual hash searched over the 8 flips and quarter-turns.

Scores are hubness-corrected (each image must single out the other) and turned into p-values against a null built from the class labels: an edited copy never changes class, so an image's best match in another class is an unrelated image. A Gumbel fit to those maxima gives p-values; views are combined by Bonferroni. Byte-identical files of the same class are always linked: hubness correction can otherwise hide verbatim copies inside a class whose images all look alike (we found this on a brain-MRI benchmark).

Calibration is best on releases with many classes. With only two or three classes, treat `--alpha` as a lower bound on the false-link rate.

## Reproducing the paper

Raw datasets go under `raw/` (or set `AUGLEAK_RAW`), timm weights under `weights/` (or set `AUGLEAK_WEIGHTS`). `run_extract.sh`, `run_detect.sh` and the other `run_*.sh` scripts run the experiments in order; set `PY` to choose the Python interpreter. Extracted features (about 600 MB) are not in the repository: `src/extract.py` rebuilds them.


```
src/manifests.py         build CSV manifests for every dataset
src/cifar_aug.py         generate CIFAR-Aug (deterministic)
src/extract.py           frozen MobileNetV3 / EfficientNet-B0 features (timm ImageNet weights)
src/exp_inflation.py     random vs group split, exposure, fresh-test accuracy      (Fig. 2, Tab. 3)
src/exp_exploit.py       accuracy vs similarity of the closest training sibling     (Fig. 3)
src/exp_detect.py        sibling recovery against known groups                     (Fig. 4, Tab. 1)
src/exp_protocol.py      evaluation protocols without metadata                     (Tab. 2)
src/exp_audit.py         PlantDoc / COVID-CXR / CIFAR-10 / brain MRI / Fruits-360 audits (Sec. 8, Tab. 10)
src/exp_repeats.py       repeat shots of one object filed as different sources
src/finetune.py          end-to-end fine-tuning study                              (App. F)
src/fig_*.py, src/make_numbers.py   every figure, table and in-text number
```

All numbers in the paper are generated by `src/make_numbers.py` from `results/`; nothing is typed by hand. `results/superseded/` keeps exploratory runs that the paper only mentions (the earlier three-class CIFAR-Aug subset, Appendix B).

Three versions of the paper share the same tables and in-text numbers: `paper_tmlr/` (TMLR), `paper_neurips/` (NeurIPS Evaluations & Datasets track) and `paper/` (ICLR 2027 format; generated tables and numbers are written here). `build_paper.sh` regenerates every figure, table and number and builds all three. Figures are drawn at each venue's text width (5.5 in for ICLR and NeurIPS, 6.5 in for TMLR). Manual judgements of candidate duplicate pairs are in `results/*_manual.json`.

Datasets: CIFAR-10 images (github.com/YoongiKim/CIFAR-10-images), PlantDoc (github.com/pratikkayal/PlantDoc-Dataset), COVID-19 image data collection (github.com/ieee8023/covid-chestxray-dataset), Brain Tumor Classification MRI (github.com/SartajBhuvaji/Brain-Tumor-Classification-DataSet), Fruits-360 (github.com/Horea94/Fruit-Images-Dataset, 15 classes), and two public leaf releases (named in the camera-ready version).
